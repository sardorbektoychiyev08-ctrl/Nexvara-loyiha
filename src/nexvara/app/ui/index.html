Office yordamchisi

Excel — birinchi real sinov

Excel ochiladi, yangi ish kitobi yaratiladi, 10 qatorli jadval kiritiladi, hisob-kitob qilinadi, formatlanadi, Documents\NEXVARA papkasiga saqlanadi va qayta ochib tekshiriladi. Hammasi sizning ko'z oldingizda bajariladi.

Excel — savdo boshqaruv paneli

144 qatorli savdo ma'lumoti, SUMIFS/IF/COUNTIF formulalari, KPI ko'rsatkichlari, 3 ta grafik, yig‘ma jadval (PivotTable) va shartli formatlash. Har bir raqam qayta ochib tekshiriladi.

Word — rasmiy hisobot

A4 sahifa, sarlavha, mundarija, bo'limlar, jadval, diagramma rasmi, izoh, kolontitul va sahifa raqamlari. DOCX va PDF saqlanadi, qayta ochib 15 ta tekshiruvdan o'tkaziladi.

PowerPoint — taqdimot

6 slayd (16:9): jadval, haqiqiy grafik, rasm, ma'ruzachi izohlari, o'tishlar va animatsiya. Matn sig'ishi va obyektlar ustma-ust tushmasligi tekshiriladi. PPTX va PDF saqlanadi.

Darsliklar va testlar

Darsliklar kompyuteringizda saqlanadi va NEXVARA ulardan mavzu bo'yicha test tuzadi.

Darsliklar papkasi
Qanday qo'shiladi: yangi darsliklarni Respublika ta'lim markazining rasmiy Telegram kanalidan PDF ko'rinishida yuklab oling va shu papkaga tashlang. Fayl nomida sinf va fan bo'lsa yaxshi (masalan 7-sinf Fizika.pdf) yoki 7-sinf nomli papkalarga joylang. Keyin «Yangilash»ni bosing.
Darslik manbalari
Rasmiy eski nashr — eduportal.uz (vazirlik portali, 2017–2019, 205 ta o‘zbekcha darslik)
Yangi darsliklar — Respublika ta’lim markazi rasmiy Telegram kanali
1-qadam (bir marta): my.telegram.org saytiga telefon raqamingiz bilan kiring → «API development tools» → istalgan nom bilan ilova yarating → App api_id va App api_hash ni shu yerga yozing. Bu bepul; ma’lumot faqat shu kompyuterda saqlanadi.
2-qadam: Telegram'ga kirish. Kod Telegram ilovangizga keladi.
Mavzu va test

AI'siz rejimda savollar darslik matnidagi ta'riflar, sanalar va raqamlardan tuziladi. «AI bilan» belgilansa, savollarni AI mavzu matnidan yozadi (kalit kerak). Word'da tahrirlab olishingiz mumkin. «Mavzuni chiqarish» mavzu matnini Word'da va darslikning asl sahifalarini PDF'da beradi.

    Testlar va Office
    AI (ixtiyoriy)

    Kalitsiz ham NEXVARA ishlaydi. Kalit qo‘shsangiz: erkin yozilgan buyruqlarni tushunadi, darsliklar bo‘yicha savollarga javob beradi, sifatliroq test tuzadi. Kalit Windows himoyalangan xotirasida (Credential Manager) saqlanadi va faqat o‘z provayderiga yuboriladi. Bitta provayder yetarli.

    Muhim: ChatGPT, Claude yoki Gemini obunasi (Plus, Pro, Max, Advanced) API krediti bilan bir xil emas. NEXVARA API orqali ishlaydi — har bir provayder saytida alohida API kalit va API krediti (balans) kerak. To‘lov NEXVARA ichida qilinmaydi: «To‘lov / Balans» tugmasi provayderning rasmiy sahifasini brauzerda ochadi. Karta raqami, CVV yoki bank parolini NEXVARA’ga hech qachon kiritmang.

    AI’ni qanday ulash mumkin (bir martalik, 2 daqiqa)
    1. Provayder qatorida «API kalitini olish ↗» ni bosing — rasmiy sayt brauzerda ochiladi. U yerda o‘z hisobingiz bilan kiring va yangi API kalit yarating.
    2. Kalitni saytdagi nusxalash tugmasi bilan nusxalang.
    3. NEXVARA’da «Buferdan kalitni saqlash» ni bosing. Kalit ekranga chiqmaydi: bepul tekshiriladi, Windows himoyalangan xotirasiga (Credential Manager) yoziladi va bufer tozalanadi.
    4. AI o‘zidan yoqilmaydi: pastdagi «AI yoqilgan» ni o‘zingiz belgilaysiz.

    Nega «Google/ChatGPT bilan kirish» emas: OpenAI, Claude va DeepSeek boshqa dasturlarga API uchun rasmiy kirish (OAuth) bermaydi — faqat API kalit. Gemini’da OAuth bor, lekin u Google Cloud loyihasi va keng ruxsat talab qiladi; Google o‘zi ham API kalitni eng oddiy yo‘l deb tavsiya qiladi. Obuna (ChatGPT Plus, Gemini Advanced…) API krediti emas.
